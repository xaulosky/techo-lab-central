# Inspección 3D del techo

Visor three.js con herramientas de dibujo. Carga `modelo.glb` (en esta carpeta o en la carpeta superior).

**Uso:** doble clic en `iniciar.bat` (requiere Python) → se abre http://localhost:8000/interfaz/

Herramientas: Navegar (V), Lápiz (D), Marcador con tipo y nota (M), Medir (R), Área (A), Borrar (E), Escala (C).
Ctrl+Z / Ctrl+Y deshacer/rehacer. Las anotaciones se autoguardan en el navegador; usa Guardar/Cargar (JSON) para respaldarlas y Captura para exportar PNG.
Escala: usa «Escala» con una distancia conocida para calibrar las medidas (por defecto 1 unidad = 1 m).
Las librerías están en `lib/` (sin necesidad de Internet).
